# INDOFLOODS - Flood vs Severe Flood Prediction

## Project Overview
This is a Machine Learning project that classifies flood events into two categories: Flood and Severe Flood.

## Objectives
- Analyze flood-related data.
- Clean and preprocess the dataset.
- Handle missing values.
- Train and compare Machine Learning models.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. K-Nearest Neighbors (KNN)
2. Support Vector Machine (SVM)
3. Naive Bayes
4. Neural Network
5. Bagging Trees
6. Boosted Trees

## Results
The Neural Network achieved 85% accuracy on the test dataset in the reported experiment.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

## Future Scope
- Improve Severe Flood detection.
- Tune model parameters.
- Test on additional flood datasets.
